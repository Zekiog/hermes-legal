# Contributing

This repository is three static HTML files: `index.html`, `privacy.html`, and `terms.html`. There is no build step.

Edit those files directly. Open the pull request against `gh-pages`. That branch is the default branch, and GitHub Pages publishes it from the repository root.

Say what changed. Opening the page in a browser is enough to check it.

## Security

Do not open a public issue for a security vulnerability. Follow [SECURITY.md](SECURITY.md).
